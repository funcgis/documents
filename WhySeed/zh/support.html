1. 关于好奇搭子

「好奇搭子」（英文名 Haoqi，工程名 WhySeed）是一款面向父母的 iOS 应用：帮你把孩子的「为什么」变成可以说出口的分龄讲法、追问与睡前话题。答案始终由父母亲口告诉孩子，应用不对着孩子直接讲课，也不要求孩子注册账号。

2. 快速开始

  1. 打开 App，进入底部「提问」。
  2. 用文字或语音输入孩子的问题，选择年龄段。
  3. 查看讲法、追问与「一起查查」话术；可点「先听一遍」试听。
  4. 愿意的话，把问答记入「日记」，或在「成长树」里浇水留下陪伴痕迹。

3. 功能说明

  • 提问讲法：分龄台词卡 + 追问引导。
  • 先听一遍：豆包语音试听（需网络）。
  • 今晚话题：睡前十分钟的小话题。
  • 好奇心日记：记录问答与孩子原话（可录音）。
  • 成长树：用浇水见证交流积累。
  • 我说错了：找补讲法，可参考云端精选示例。
  • 敏感话题：生死、身体、金钱等更谨慎的讲法思路（默认本机）。

4. 会员与课包

订阅与主题课包通过 Apple 应用内购买完成，价格以购买时展示为准。续费、取消与退款遵循 App Store 规则。

管理订阅：iPhone「设置 → Apple ID → 订阅」。点「恢复购买」只会恢复当前 Apple ID 已购买的权益。

5. 系统权限

  • 麦克风 / 语音识别：口述问题、日记录音。
  • 通知：睡前话题、生日挖瓶提醒（需你主动开启）。

可随时在「设置 → 好奇搭子」中关闭；关闭后对应功能不可用，不影响已保存的本地数据。

6. 常见问题

为什么提示「本地讲法」？
敏感话题默认本机处理；网络异常或后端暂时不可用时也会回退本地占位，可稍后重试。

语音像机械音？
请确认网络正常，并使用 TestFlight / App Store 正式包（Debug 配置可能不同）。

换机后日记还在吗？
当前版本以本机数据为主，换机前请自行备份你看重的内容。
