1. 关于鲜期

鲜期（英文名 FreshQi，工程名 FreshDay）是一款 iOS 应用，帮助您管理药品、食品、化妆品、日用品、数码保修与证件合约等物品的到期日，并通过本地通知与小组件提前提醒。

无需注册账号。主界面为五个入口：首页 · 归档 · 添加（中间「+」）· 数据 · 设置。物品数据默认保存在本机。

2. 快速开始

  1. 打开 App，点底栏中间绿色「+」添加物品（也可稍后在首页管理）。
  2. 选择品类，填写名称与到期相关日期；开通 Pro 后可用扫码或拍照识字辅助填写。
  3. 保存后，本机会按默认规则安排提醒。自定义提醒天数需开通 Pro（设置 → 通知设置）。
  4. 用完或处理完后，在首页向左滑归档；可在「数据」页查看趋势与徽章。
  5. 在主屏幕或锁屏添加鲜期小组件，随时查看临期物品。

更完整的操作说明请在 App 内打开：设置 → 使用说明。

3. 功能说明

首页

按「在用 / 即将到期 / 已过期」与品类筛选；点物品可编辑。证件合约出现在「虚拟物品」区域。向左滑可归档并选择处置方式。

分类

支持：药品、食品、化妆品、日用品、数码、证件合约、其它。不同品类有不同的日期字段与默认提醒规则（例如化妆品支持开封后可用月数，数码侧重保修期，证件合约按有效期管理）。

归档

记录已处理物品与处置方式（正常用完、过期丢弃、转让清理、破损变质等）。可选填写金额，用于浪费 / 回血统计。归档页可筛选与搜索；轻点不会进入编辑；长按可「恢复」回首页或永久删除。

数据

根据归档结果展示已处理 / 浪费 / 回血、月度趋势、品类排行、零浪费挑战与徽章。页面下方有「本年迄今」实时摘要；上一年的正式年度报告于每年元旦起可查看（可点「查看我的报告」，或从元旦提醒进入）。金额只统计您归档时选填的数字。

条码扫描（Pro）

对准包装条码扫描，可尝试自动查询商品名称等信息。联网查码可能受次数限制：年订约每年 80 次，永久约每年 160 次。查不到时可改用手填或拍照识字。

拍照识字（Pro）

拍摄包装上的名称、生产日期、保质期等，辅助填入表单。识别在您的设备上完成；结果请务必核对后再保存。

本地提醒

到期前按规则发送本地通知。请在系统设置中允许通知。免费版使用内置默认规则；自定义偏移与偏好需 Pro。归档后，该件未发出的提醒会取消。

断舍离助手

设置 → 断舍离助手：按过期与临期情况给出健康分（0–100），并分组列出建议优先处理的物品。有在用物品时，设置菜单旁也会显示分数（如「72分」）。

小组件

提供临期速览、分类清单、锁屏高危药品等小组件。数据来自 App 与小组件之间的本机共享，无需账号。

备份与导出（Pro）

设置 → 数据备份：可将数据导出为 JSON / Excel（可选含照片），或从备份导入，便于换机迁移。数据页本身不提供导出。

4. 鲜期 Pro

免费版支持手动录入、基础提醒、归档、数据洞察、徽章、断舍离助手与小组件。Pro 主要解锁：

  • 联网条码商品查询（年订约 80 次/年；永久约 160 次/年）
  • 拍照识字
  • 自定义通知 / 提醒设置
  • 备份导出 / 导入

提供年订阅与终身买断（以 App 内与 App Store 展示价格为准）。购买与恢复购买均通过 Apple ID 完成。

「恢复购买」只会恢复您当前 Apple ID 已购买过的权益；从未购买过时会提示没有可恢复记录，这是正常现象。

5. 系统权限

  • 相机：扫描条码、拍摄包装文字或照片。
  • 照片：从相册选择图片附加到物品。
  • 通知：发送到期前提醒与年度报告提醒。

可随时在「设置 → 鲜期」中关闭某项权限；关闭后对应功能不可用，不影响其它已保存数据。

6. 常见问题

为什么今天没收到提醒？

  • 检查系统通知是否已开启。
  • 确认该品类提醒已启用，且规则包含「当天」。
  • 若在提醒时刻之后才保存或修改物品，可能稍后再收到补发通知。

扫码查不到商品？

  • 部分商品未收录，请手填或使用拍照识字。
  • 查码次数用完后，可改用手填 / 识字；曾经保存过的条码会尽量复用。

拍照识字不准？

光线不足、反光、字体过小都会影响识别。请尽量拍清晰、正对日期区域，并在保存前核对。

归档里点不开编辑？

归档页只做历史浏览。若要改资料：长按 → 恢复到首页 → 编辑 → 需要时再归档。

年度报告什么时候出炉？

正式报告回顾上一年，每年 1 月 1 日起可在数据页查看。若开启了通知，元旦还会收到提醒；一月内首次打开 App 也可能自动弹出一次（若上一年有归档记录）。

小组件不更新？

先打开一次主 App，再下拉刷新主屏幕；系统会按策略刷新小组件，并非实时秒级同步。

如何彻底删除数据？

删除 App 会清除本机物品与设置。若曾导出备份文件，请自行删除设备或云盘中的备份文件。
